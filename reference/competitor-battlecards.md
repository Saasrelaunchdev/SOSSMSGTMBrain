# Competitor battlecards

Load for: sales-free objection replies, comparison pages, partner materials, and any copy that names or implies a rival. Distills both runs' Phase 2 (summary, advantage, vectors). Never name a rival as dishonest; state mechanics. Grade C figures stay internal.

**The weak point to own:** every request is shared. Say it first: "Every matched contractor sees the request at once. The first to accept gets it. A request you do not win costs you nothing."
